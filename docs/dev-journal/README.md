# 開發日誌（Dev Journal）

append-only 的開發記錄：什麼時候做了什麼、為什麼做。寫給之後
（包括未來的自己）想理解 codebase 為什麼長這樣的人。

## 怎麼使用這個資料夾

- **一個「有意義的工作段落」寫一篇**——不是每個 commit 寫一篇。
- **檔名：** `YYYY-MM-DD-short-slug.md`。
- **語氣：** 教學性。假設讀者還不熟 Docker 或 FastAPI，解釋**為什麼**
  這樣決定，不只寫做了什麼。
- **要包含：** 目標、加了/改了什麼、怎麼驗證、以及值得下次記住的眉角。
